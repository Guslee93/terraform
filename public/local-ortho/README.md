# Local aerial photos (Visual Lab preview only)

Put a north-up screenshot from norgeibilder.no here, named after the site:

- `compact-infill.png` — centre 59.9235 N, 10.7580 E, tile about 624 × 734 m
- `sloped-edge.png` — centre 59.89825 N, 10.77375 E, tile about 652 × 790 m

(`.jpg` and `.webp` work too.) Open the Visual Lab with the IDENTITY style; the "Aerial photo (local)"
card lets you line the photo up with the buildings, grey it and set its brightness. The alignment is
remembered in your browser.

**Everything in this folder except this README is git-ignored.** Kartverket's terms allow screenshots
with credit, but draping them on the terrain and publishing them needs written permission
(`docs/data/orthophoto-source.md`). Do not commit, upload or deploy these files.
