## Goal

Ship two curated Oslo demonstration packages as static, versioned assets, loaded through a validated manifest and rendered in the local ENU frame with reliable north orientation and usable camera presets.

## Delivered

1. **Two packages** — Compact Infill (137 simplified context buildings) and Sloped Edge (33 simplified buildings, 31 m relief).
2. **Assets per package** — `manifest.json`, `terrain.json` (13 × 13 DTM1 samples), `buildings.json` (simplified OSM footprints and heights), `study-area.json` (authored, not cadastral), `attribution.md`.
3. **Manifest contract** — `parseSiteManifest` and package parsers validate schema, units, CRS metadata, camera presets, statistics, closed/simple rings and finite geometry at load.
4. **Coordinate transform** — offline Python pipeline records WGS84 origin, NN2000 vertical datum, local tangent-plane projection and source provenance. No runtime GIS calls.
5. **Scene layers** — terrain mesh + mesh grid + solid skirt, merged context-building geometry, dashed study boundary; Inspector toggles for all three.
6. **Camera** — orbit/pan/zoom, fit site (`F`), perspective presets: Isometric, Top, North, South, Eye Level; animated transitions with reduced-motion snap. Orthographic presets are rejected in v1.
7. **Orientation** — dynamic compass derived from the camera basis and a scale bar derived from camera–target distance.
8. **Performance** — one merged context geometry, one terrain mesh, ~5 draw calls; measured 60.1 fps at 1440×900 on Apple M1 Pro / ANGLE Metal; 39.6 fps on software SwiftShader (not representative).

## Provenance

- Building footprints: © OpenStreetMap contributors, ODbL 1.0; simplified with 1.2 m tolerance; building relations omitted.
- Terrain: © Kartverket DTM1, CC BY 4.0; sampled through the open height API and recentered to the site origin.
- Study boundary: authored rectangle, explicitly **not a cadastral parcel**.
- Attribution files are shipped in each package and exposed in the studio footer, Inspector and About page.

## Acceptance evidence

- Both packages load with only local static assets; no GIS/API calls at runtime.
- QA: manifests, units, provenance, boundary closure/simplicity, 170 building footprints all simple and finite, 13 × 13 terrain grids finite, statistics consistent.
- Camera presets and layer toggles exercised by Playwright; screenshots at four viewports and top view at three desktop sizes.
- 60.1 fps at 1440×900 on hardware GPU; 0 page errors.
- `npm run typecheck`, `lint`, `test` (33), `build`, `test:e2e` (2) pass.

## Out of scope

Live GIS calls, MapLibre, editable parcels, cadastral boundaries presented as official, orthographic camera, street linework, setback rendering and selected massing (M2/M3).

## Follow-ups

- Increase terrain resolution if M2 clearance checks need finer grade.
- Add a Kartverket response checksum.
- Hide/deemphasize the compass near eye-level where its 2D projection degenerates.
- Adapt camera framing for narrow mobile aspect ratios.
- Document the Python `certifi` prerequisite for the offline pipeline.

## Risks

- Licensing ambiguity: OSM ODbL share-alike applies to the derived building package; attribution and licence links must remain.
- Sloped terrain causing mass intersections: explicit base elevation and clearance warnings, no auto-deformation.
- Asset size vs load time: current packages are ~95 KB and ~32 KB; well within budget.
